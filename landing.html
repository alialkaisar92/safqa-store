📘 دليل الاستخدام الكامل

كل خطوة بالتفصيل — من التسجيل لحد سحب أرباحك

👤

1. إنشاء حساب

  1. دوس 「ابدأ التسويق مجاناً」 أو 「سجّل مجاناً」
  2. اختار تاب 「إنشاء حساب」
  3. اكتب اسمك + رقم موبايلك + كلمة سر (6 أحرف فأكثر)
  4. دوس 「إنشاء الحساب والبدء」 — هتدخل المتجر فوراً
🛍️

2. التسوق والسلة

  1. تصفّح المنتجات ولاحظ شارة المخزون (متوفر / متبقي / نفد)
  2. دوس على المنتج لفتح تفاصيله
  3. حدّد الكمية بأزرار − و +
  4. دوس 「أضف إلى السلة」 — العداد فوق يتحدث فوراً
💳

3. إتمام الطلب

  1. من السلة دوس 「إتمام الطلب للعميل」
  2. اكتب اسم العميل وتليفونه وعنوانه
  3. اختار المحافظة ثم المدينة
  4. حدّد سعر الشحن وعمولتك، راجع الإجمالي ثم أكّد
📊

4. متابعة أرباحك

  1. 「طلباتي」 — كل طلباتك وحالتها
  2. 「الإحصائيات」 — أرباحك ومبيعاتك بالأرقام
  3. 「حسابي」 — بياناتك وتعديلها
  4. 「الدعم」 — كلّمنا وابعث صور أو صوت
🎁

5. الكسب بالمشاركة

  1. انسخ رابط التسويق الخاص بيك من أي منتج
  2. شاركه على فيسبوك / واتساب / تيك توك
  3. لما حد يشتري من رابطك، العمولة تتضاف لرصيدك
  4. لما رصيدك يكبر، روح 「السحب」 واسحب فلوسك
❓

6. أسئلة سريعة

  1. الاشتراك مجاني 100% وبدون رأس مال
  2. العمولة تصل حتى 30% حسب المنتج
  3. السحب عبر فودافون كاش / إنستاباي / بنك
  4. أي مشكلة؟ ابعتلنا من صفحة الدعم
